# 跨专业微型示例与回归检查

以下例子只展示判断结构，不代表真实资源、周期、学校要求或论文结论。

## 材料/化学：历史设备路线

组内论文方法部分显示四年前使用设备 X 完成表征，因此历史方法事实可为 A。当前设备状态、排期、培训和耗材仍为 C，路线暂定 AMBER。主线只增加一个变量；MVP 用现有基础表征先判断方向。若平台负责人无法在切换日前确认 X，则 Plan B 改用可预约测试，Plan C 转为已有数据的比较和机制边界分析，但先确认这种成果是否被学校认可。

预期行为：不能写“组里有设备 X”；未知设备项不得默认计 3 分。

## 生物/医学：伦理和样本是硬门

论文证明过去建立过某模型，不证明当前样本、关键人员和伦理批件仍有效。伦理或授权无法在启动前取得时，原路线为 RED，不因创新性或导师兴趣而提升。可替代为已获授权数据的分析或方法验证，但新路线重新过毕业门和数据许可门。

预期行为：不能建议先收样本后补审批；合规 FAIL 覆盖评分。

## 计算机/数据：论文代码不等于可复现

上传论文和仓库可证明算法描述与公开代码存在；数据许可、版本、算力、评价脚本和基线结果要分别核验。先运行最小基线和数据完整性检查。保底线是可复现基线与稳健比较，主线才加入新模型。若 2 周内基线仍无法复现，切到简化模型或公开数据，但不把工程失败包装成算法创新。

预期行为：身份核验和主张支持核验分开；MVP 有数值/质量判据与切换日。

## 教育/经管/社会科学：访问权会过期

往届论文使用某学校、企业或问卷样本，只证明过去获得过访问。当前招募、伦理、数据授权、样本量和缺失率均需重新确认。若访问权在最晚日期前无法书面确认，主线降级为 AMBER 或 RED；保底线可考虑已授权历史数据、小范围方法验证或公开数据，明确外推边界。

预期行为：不得把导师口头说“应该能拿到”升级为 A。

## 理论/人文：资源风险不只来自设备

理论或人文研究的关键资源可能是语料访问、档案开放、语言能力、版本校勘、版权、指导密度和可接受的论证范围。MVP 可是一组边界明确、材料可获得的核心文本与可检验论证链。若核心档案不可访问，Plan B 缩小材料范围，Plan C 改为公开版本的比较研究；仍需确认最低成果是否满足学位要求。

预期行为：不能因为“无需实验”就自动判低风险。

## 四个回归场景

更新 Skill 后至少检查：

1. **只上传组内论文**：应先审计并提问，不能直接给 GREEN。
2. **用户两轮都不回答**：应停止追问，给条件方案和最小补证动作。
3. **高创新路线合规 FAIL**：必须判 RED，不能被总分救回。
4. **评分未知很多**：输出覆盖率和暂定排序，不能给无依据精确结论。
